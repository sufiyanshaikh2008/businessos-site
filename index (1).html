Your books stay right, even on a busy day

The foundation follows the rules that matter for money and for privacy.

Separate businesses

Each business’s data is walled off. Nobody sees another’s records.

Exact money

Amounts are stored in whole paise, so totals never drift by a rounding error.

A trail for every change

Important actions are logged, and issued invoices are adjusted, never overwritten.

Permissions on the server

Roles are enforced in the backend, not just hidden in the screen.

Run it on your own computer

You need Node.js 20+, pnpm 9+ and Docker. Then paste these into a terminal.

# 1. Set up your settings and database cp .env.example .env docker compose up -d postgres # 2. Install and prepare pnpm install pnpm db:generate pnpm db:migrate # 3. Start each app in its own terminal pnpm dev:api pnpm dev:web pnpm dev:mobile
